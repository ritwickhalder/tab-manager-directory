# Browser Tab & Session Manager Directory
A comprehensive directory of browser tab managers, session managers, workspace managers, tab organizers. This directory aims to list every tab and session managers for all browsers so feel free to raise a PR to add your extension in the format below. Please DO NOT edit existing list unless some information is wrong or needs to be updated for any valid reason (not promotional).
